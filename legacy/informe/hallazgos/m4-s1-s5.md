## Huella SMB observada (sin autenticar)

```text
SMB  10.10.10.14  445  SRVOLD  [*] Windows Server 2016 Standard Evaluation 14393 x64 (name:SRVOLD) (domain:SRVOLD) (signing:False) (SMBv1:True)
```

Eso confirma **SMBv1 activo** y **firma SMB desactivada** (S5), y es coherente con S1. El login con `Admin13.-` falló (`STATUS_LOGON_FAILURE`); no se insiste con fuerza bruta. Para S3 hay que confirmar la clave real con el dueño o resetearla desde la consola.
