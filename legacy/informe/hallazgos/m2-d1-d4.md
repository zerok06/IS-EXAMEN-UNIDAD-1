## D1 · CVE-2022-0543 · Redis Lua sandbox escape

| Campo | Valor |
|---|---|
| Servicio/versión | Redis 6.2.6 (compilado de fuente; versión sin cambiar) |
| CWE | CWE-94 |
| CVSS | **10.0 Crítica** |
| Descripción | Escape del sandbox Lua en paquetes Debian/Ubuntu → RCE como `redis` |
| Validación | `redis-cli -h 10.10.10.12 PING` → `PONG`; `INFO` → `6.2.6`; `CONFIG GET requirepass` vacío |
| PoC Lua | `EVAL 'local l=package.loadlib(...)'` → `ERR ... nonexistent global variable 'package'` |
| Estado | 🟡 Acceso sin autenticación validado; **RCE no reproducible** (`enable_strict_lua`) |
| Impacto | Lectura/escritura del almacén; no se obtuvo shell |
| Mitigación aplicada | `requirepass` en `/etc/redis.conf` + `systemctl restart redis` (Moodle no usa Redis con auth: sin cambios en app) |
| Retest | `PING` sin clave → `NOAUTH`; desde M6 → timeout (UFW solo M1) |
| Evidencia | `F04-001`, `F04-001b`, `F04-018`, `F06-008`, `F07-005` |
